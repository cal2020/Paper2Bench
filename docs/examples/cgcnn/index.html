## Evaluation Details

- **Metrics Definitions**:
  - **Mean Absolute Error (MAE)**: Calculated as the average of the absolute differences between predicted and actual values for each property.
  - **Formation Energy Reference State**: The reference state for formation energy is based on DFT calculated values from the Materials Project.

- **Post-Processing**:
  - For each property, ensure that the predictions are averaged over the test set to obtain the final MAE.
  - Check for k-point convergence and ensure that the results are smoothed if necessary.

- **Aggregation Strategy**:
  - Calculate MAE for each structure, then aggregate results per composition, and finally compute an overall MAE across all properties.

## Implementation Notes

- **Key Pitfalls**:
  - Ensure that the training, validation, and test splits are correctly implemented to avoid data leakage.
  - Monitor convergence of the CGCNN during training; adjust learning rates and regularization as necessary to prevent overfitting.

- **Input-File Conventions**:
  - Follow the input conventions specified in the CGCNN documentation for defining atom and bond feature vectors.
  - Ensure that the output files are parsed correctly to extract the required observables.

- **Order of Operations**:
  - Train the model on the training set before validating on the validation set.
  - Use the best-performing model from the validation set to evaluate the test set.
