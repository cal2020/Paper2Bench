## Evaluation Details

- **Metrics Definitions**:
  - **F1-Score**: Harmonic mean of precision and recall. Use `sklearn.metrics.f1_score` with `average='macro'` for multi-class tasks.
  - **Matthews Correlation Coefficient (MCC)**: Use `sklearn.metrics.matthews_corrcoef` for binary classification tasks.
  - **Computational Cost**: Measure FLOPs using the formula for the number of operations in the forward pass of the model architecture.

- **Post-Processing of Outputs**:
  - For F1-scores, ensure to handle multi-class averaging appropriately. Use `average='macro'` for balanced class distributions.
  - For MCC, ensure to handle cases with zero true positives to avoid division by zero errors.

- **Aggregation Strategy**:
  - Aggregate results per dataset to obtain average scores across tasks. For overall performance, calculate the mean of the average scores across all tasks.

## Implementation Notes

- **Key Pitfalls**:
  - Ensure that the training and test datasets are properly split to avoid data leakage, especially when using the same sequences for different tasks.
  - Be cautious of the input length limitations of DNABERT and ensure that sequences longer than 512 tokens are handled appropriately (e.g., by truncation or splitting).
  - Maintain consistent preprocessing across all models to ensure fair comparisons.

- **File Format Conventions**:
  - Use FASTA format for input sequences. Ensure that all sequences are in the correct format before processing.
  - For output, ensure that predictions are saved in a structured format (e.g., CSV) for easy evaluation.

- **Order of Operations**:
  - Perform deduplication of sequences before splitting into training, validation, and test sets.
  - Ensure that all preprocessing steps (e.g., filtering, tokenization) are completed before model training and evaluation.
