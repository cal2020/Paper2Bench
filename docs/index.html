Convert academic papers into agent benchmarks.

Drop a paper. Get back a research question, the models and datasets the paper used, and a ground-truth experimental plan — ready to hand to a coding agent. ~2-3 minutes per paper.

v0.3.0 Python SDK + CLI · OpenAI & Anthropic supported · Built on the Paper2Bench pipeline

What you get from a paper

One paper in, one benchmark task out.

Every paper produces a problem tree (Root → Research Questions → Experiments) plus four artifacts: a parsed config, an agent-facing instruction, a ground-truth plan for evaluators, and the original PDF.

Problem tree — CGCNN (example)
📄 Root: Predict bulk material properties from crystal structure
├─ RQ1: Can a graph CNN match DFT accuracy on formation energy?
│ └─ Exp: train on Materials Project, MAE on test set (Fig 2b, Tbl I)
├─ RQ2: Does the model generalize to elastic moduli?
│ └─ Exp: bulk & shear modulus on 2,041 structures (Fig S5)
└─ RQ3: Can per-atom site energies be extracted?
└─ Exp: 18,928 perovskite crystals (Fig 3b)

Each run writes to output/tasks/<task_id>/:

  • tree.json — the parsed problem tree
  • task_config.yaml — models, datasets, budget, constraints
  • instruction.txt — what the agent sees (no leaked methodology)
  • instruction_gt.txt — ground-truth experimental plan, for evaluators

Install

Use it from Python or the CLI.

The repo is private; install from GitHub with a personal access token (PAT). Set OPENAI_API_KEY (or ANTHROPIC_API_KEY) in .env or your environment.

Install from GitHub (private repo)

pip install "git+https://<PAT>@github.com/AbhayAnandUCSD/Paper2Bench.git@v0.3.0"

For Claude support add the optional extra:

pip install "paper2bench[anthropic] @ git+https://<PAT>@github.com/AbhayAnandUCSD/Paper2Bench.git@v0.3.0"

Run the full pipeline (CLI)

paper2bench run \
  --task-id reversal_curse \
  --query "The Reversal Curse Berglund" \
  --research-question "If an LLM is fine-tuned on 'A is B,' does it learn 'B is A'?" \
  --output-dir ./output/ \
  --auto

Other subcommands: download, parse, classify, extract, render, plan, verify, specextract, generate.

Or use the Python SDK

import paper2bench

result = paper2bench.run(
    pdf="paper.pdf",
    research_question="Does X improve Y?",
    output_dir="./output",
    # paper_type=                     # auto-classified if omitted
    # api_key="sk-..."                # or use OPENAI_API_KEY / ANTHROPIC_API_KEY env
)

print(result.paper_type)               # llm_evaluation | novel_architecture | empirical_study
print(result.instruction_path)         # ./output/tasks/<task_id>/instruction.txt
print(result.instruction_gt_path)      # ground-truth plan
print(result.config)                   # parsed task_config.yaml as dict

Stage functions are also importable for fine-grained control: parse_paper_to_tree, classify_paper, extract_yaml_from_pdf, render_instruction, generate_supplementary_plan, build_instruction_gt, verify_instruction_gt, extract_paper_spec, generate_variants, chat.

How it works

Five LLM-driven stages, ~2-3 minutes end-to-end.

STAGE 1
parse
PDF → 3-level problem tree (Root → Research Questions → Experiments).
STAGE 2
classify
Auto-detect paper archetype to pick the right extraction prompt.
STAGE 3
extract
PDF + RQ → task_config.yaml (HuggingFace-validated).
STAGE 4
render
Template the YAML into instruction.txt for the agent.
STAGE 5
plan
Build instruction_gt.txt — the ground-truth experimental plan.
